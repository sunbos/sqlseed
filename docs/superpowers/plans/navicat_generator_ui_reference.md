# Navicat 数据生成器 UI 细化参考（逐截图）

**来源**: `示例UI/生成数据类型/` 46 张 Navicat 16 截图 —— `生成数据类型1/2.png` 为整体类型统计（7 大类 44 种），其余 44 张为逐生成器面板（2026-08-30 逐张提取）。
**目的**: 作为 sqlseed-web 属性面板的**检查基线**——记录每个生成器面板的布局、可配置参数、控件类型、默认值与可见选项，供后续逐项核对。
**配套文档**: 差距分析与落地路线见 [navicat\_generator\_parity.md](./navicat_generator_parity.md)（本文只记录截图事实，不做差距判断）。

## 1. 整体布局（生成数据类型1/2.png）

### 1.1 窗口结构

```
┌─ 数据生成（macOS 窗口）──────────────────────────────────────┐
│ 🟢 数据库图标 + 连接名（sqlseed_demo / main）                    │
│ ┌─ 数据库对象 ────────┬─ 属性面板 ──────────────────────────┐ │
│ │ 表 (6) 可勾选树      │ 字段名（蓝色链接样式）                │ │
│ │  表 → 列（两级勾选） │ 类型副标题（灰色小字，如 DATE/text）   │ │
│ │  列后括号=当前生成器  │ 生成器: [下拉，7 类分组]              │ │
│ │                    │ ── 类型专属参数区 ──                  │ │
│ │                    │ 预览: <例值>  刷新（蓝色链接）          │ │
│ │ [搜索框]           │ ── 底部通用区（默认值/NULL/唯一/链接） ──│ │
│ │                    │ [重置属性]                            │ │
│ └────────────────────┴──────────────────────────────────────┘ │
│ [保存配置文件▾] [加载配置文件] [选项] [表生成顺序]   [上一步] [下一步]│
└──────────────────────────────────────────────────────────────┘
```

要点：

* **左树**：表/列两级 checkbox；选中列高亮蓝条，列名后括号实时标注当前所选生成器（如 `signup_date(日期时间)`）；树底有搜索框。

* **右面板**：字段名 + 类型副标题 + 生成器下拉 + 参数区 + 预览 + 底部通用区 + 重置属性。

* **底部工具栏**：保存配置文件（带下拉箭头）、加载配置文件、选项、表生成顺序；右侧上一步/下一步。

### 1.3 底部通用区控件矩阵

| 数字 / 日期时间 / 日期 / 时间 / 布尔值 / UUID / 正则表达式                   |  ✓  |   ✓  |  ✓  |  ✓  | 有             |
| 姓名 / 电话号码 / 电子邮箱 / 社交网络ID / 信用卡卡号 / 信用卡日期                  |  ✓  |   ✓  |  ✓  |  ✓  | 有             |
| 公司名称 / 条码 / SKU                                            |  ✓  |   ✓  |  ✓  |  ✓  | 有             |
| IP地址 / MAC地址 / 网址 / 主机名                                    |  ✓  |   ✓  |  ✓  |  ✓  | 有             |
| 枚举 / 文本                                                    |  ✓  |   ✓  |  ✗  |  ✗  | 有             |
| 产品名称 / 重量单位 / 支付方式 / 信用卡类型                                 |  ✓  |   ✓  |  ✗  |  ✓  | 有             |
| 性别 / 称谓 / 婚姻状况 / 职位名称 / 部门 / 行业 / 地址 / 城市 / 产品类别 / 颜色 / 尺寸 |  ✗  |   ✓  |  ✗  |  ✓  | 有             |
| 地区                                                         |  ✗  |   ✓  |  ✗  |  ✓  | 有（额外多「将值转换为」） |

| 序列 / 外键                                                    |  ✗  |   ✗  |  ✗  |  ✗  | 序列有（无刷新）/外键无  |

## 9. 检查要点（后续核对清单）

1. **布局**：左树两级勾选 + 列名括号实时标注生成器；右面板"字段名/类型副标题/生成器下拉/参数区/预览/通用区/重置属性"七段式；底部四按钮 + 上一步/下一步。
2. **控件形态**：日期/时间用「文本框 + `...` 选择按钮」；范围用双数字框；词表用复选列表；可编辑值集用 textarea/多行列表框；只读正则用禁用态 textarea 展示。
3. **联动禁用**：一整天→时间框禁用；整数/小数→小数位数；全部/工作日/自定义→星期组；最大→循环；图像/文件夹模式互斥分支。
4. **通用区按类型裁剪**：词表类无默认值/唯一；序列/外键全无；图像或二进制仅 NULL 且无预览。
5. **百分比默认 5**，未勾选时禁用态。
6. 每个面板左下独立「重置属性」按钮。
