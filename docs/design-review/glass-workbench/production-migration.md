# 正式界面组件迁移核对

核对日期：2026-09-27。基准为已认可的 [交互样板](http://127.0.0.1:8630/static/design-system.html) 和 [组件标准](component-standard.md)；正式入口为 [工作台](http://127.0.0.1:8630/#/workbench)。

## 实现方式

样板与正式入口共用 `style.css`、组件 CSS、字体文件和交互模块。迁移通过修复正式调用处及旧样式覆盖完成，不复制一份样板 CSS，也不恢复历史 connect/wizard/browse 页面。后续改动应同时检查样板中的状态和下表中的真实入口。

| 正式入口 | 共用的规格／模块 | 本轮核对与修复 |
| --- | --- | --- |
| 应用导航、首次连接、切换连接 | `navigation.css`、`connection.js`、共享按钮、表单、滚动锁与弹窗材质 | 连接窗口补齐 `wb-modal` 和 header/body/footer；长连接／文件列表只滚动正文。必填与端口错误关联字段，编辑后清除。 |
| 工作台顶栏、配置上下文、侧栏 | `workbench.css`、`ui.js`、共享选择控件 | 当前查看与生成勾选独立；搜索、全选、表数量、全局设置保持统一字体和状态。 |
| 全局引擎／地区设置 | `dropdown.js`、`provider-guide.js` | 英文引擎名使用圆角 UI 字体；长列表隐藏滑块并提供方向提示；探索／滚动不提交，取消不应用。 |
| YAML、保存／重命名、打开配置、生成确认 | `ui.js`、共享输入、单选与按钮 | 技术配置保持等宽；弹窗独立滚动、底部操作可见。生成确认保持追加默认与禁用重置计数的语义。 |
| 字段信息与规则抽屉 | `editor.js`、`workbench.css`、`date-picker.js` | 核对普通、JSON、派生、外键、数据库分配、NULL／唯一、高级参数。来源字段及原生方法是代码字体；日期自定义星期修复居中及空选择的组错误状态。 |
| 内嵌预览、批量预览、数据库当前数据 | `preview.js`、`table-data.js` 及组件 CSS | 字段名等宽、记录内容 UI 字体；表头稳定底色。元信息 11px、规则说明 12px；禁用按钮不保留可点击悬停反馈，错误与警告颜色不被通用段落覆盖。 |
| 关系图、范围切换、检查器、依赖顺序 | `graph.js`、`graph-layout.js`、`graph-clarity.css` | 选中底板短过渡；范围立即生效，不改生成勾选。沿用少折优先且避开节点的路径。依赖顺序按钮移除旧悬停描边，复用柔阴影。 |
| AI 助手 | `ai.js`、`ai.css`、共享模态和表单 | 范围选择统一 17px；字段标识与自然语言各用对应字体；范围错误及预览警告使用语义色。未配置时分析禁用，未调用模型。 |
| 配置管理 | `configs.js`、`configs.css` | 卡片、筛选空态、名称校验、导入导出与删除确认沿用共享组件；操作文字 13px，技术修订号保留等宽。 |
| 运行记录及快照 | `runs.js`、`runs.css` | 失败与中断分别使用错误／警告色；数字使用等宽数字。刷新按记录身份保留列表节点、快照展开、代码滚动和本详情焦点，不抢其他控件焦点。 |
| 设置：AI、插件与版本、外观 | `settings.js`、`settings.css`、`theme-control.js` | 检测／加载／刷新状态绑定实际成功、错误与警告；重试或编辑清除旧状态。外观共用浅色／深色／系统选择器，不修改业务配置。 |
| 所有正式折叠区 | `disclosure.css` | 原生 summary、统一箭头；内容 `flow-root` 将子项 margin 纳入高度过渡，关闭立即 inert，动画结束释放裁切。 |

## 当前验证证据

- Windows Chromium 实际访问四个正式页面，并操作连接／文件浏览、全局设置、YAML、日期规则、批量预览、当前数据分页、生成确认、AI 未配置范围、配置重命名／筛选空态、运行快照与外观选择。
- 字体实际诊断：中文工作台标题使用 `ChillRoundGothic_Medium`；正式引擎菜单的 Faker 混排项使用 `ChillRoundGothic_Regular`；YAML 保留原 `--mono`。不以 CSS 声明代替实际字形检查。
- 星期复选框实测 17px、上边距 0；取消全部后组为 `aria-invalid=true`、错误色边缘且应用禁用；重新勾选恢复。取消抽屉不应用临时编辑。
- 1144×816 当前数据窗口表头为深色稳定实底，分页读取第 51–100 行；footer 在视口内。1144×872 连接窗口正文内容高 873px、可视高 667px，footer 仍在视口内。
- 1440×900 正式图范围按钮使用 160ms 过渡；切换范围后四张表的生成勾选保持不变，连续八次布局采样相同。390×844 YAML 窗口宽 344px，底部操作在视口内，页面无横向溢出。
- 正式运行详情打开快照后刷新，仍保持展开。异步轮询中的快照／焦点／滚动及不同记录隔离由新增 Node 行为回归覆盖。
- 正式页面媒体仿真：减少动态效果时按钮过渡为 0s；减少透明度时阅读层为 `rgb(250,252,251)`；强制颜色时复选框恢复 `appearance:auto`。仿真结束已清除。
- 完整 Node 前端回归 **734/734 通过**。临时真实 SQLite 的 HTTP 工作流与文档同步测试 **22/22 通过**。测试数据库与用户当前连接隔离。

浏览器只读验证使用已有 `shop_demo.db`。打开生成确认时正式流程保存了当前四表配置；没有点击“写入数据库”、调用 AI 或安装组件。AI 建议结果、运行失败／中断及安装维护状态由源码审计与行为回归覆盖，未冒充本次真实外部服务视觉验收。macOS、Linux、Safari、Firefox 仍需对应设备检查；本次结论为正式入口已接入统一规格，不是所有平台或整站 WCAG 认证。
