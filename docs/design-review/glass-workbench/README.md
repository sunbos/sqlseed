# 玻璃工作台交互原型

这是一版独立的跨平台 Web 视觉与交互设计原型，使用内置电商演示数据。
不加载正式应用、不请求业务 API、不连接或写入任何数据库。所有配置和运行记录只保存在当前页面内存中，刷新即重置。

## 本地预览

从仓库根目录运行：

```powershell
.\.venv\Scripts\python.exe -m http.server 8631 --bind 127.0.0.1 --directory docs/design-review/glass-workbench
```

然后访问 <http://127.0.0.1:8631/>。现有工作台仍位于 <http://127.0.0.1:8630/>，原型右上角提供对照入口。
不需要 npm、构建步骤或外部字体/CDN。也可直接打开 `index.html`。

## 可体验的操作

- 搜索、查看表与选择生成范围分别独立；修改每张表的生成行数。
- 切换字段规则、演示预览和表间关系；预览列标题打开字段规则。
- 右侧抽屉编辑姓名、邮箱域名、数值范围、选项和日期；无效输入阻止应用，取消丢弃草稿。
- 切换演示配置的生成引擎、语言与种子；样例由原型中的小型本地函数构造，不调用真实 Faker/Mimesis。
- 检查所选表、行数、种子和依赖，确认后模拟生成；运行中可取消，完成后记录模拟结果。
- 将演示配置保存到当前会话并重新打开。
- 右上角外观设置提供柔雾、清透、纯净三个材质强度，以及减少动态效果。
- 原生 dialog 支持 Escape、焦点约束和关闭后恢复焦点；表视图标签支持方向键移动焦点、Enter/Space 激活。

## 设计与实现边界

- 玻璃用于外层框架和操作区域；清透模式的数据区使用 66% 中性白底与背景模糊，保留适合密集文字的阅读层，柔雾与纯净模式维持更厚的底色。
- 默认使用清透材质，降低外壳与侧栏的叠加遮盖；柔雾与纯净保留为可选项。系统要求减少透明度时默认使用纯净，用户可在原型内手动覆盖。
- 圆角分为外壳 14 px、面板与弹窗 10 px、按钮与输入框 6 px，保持统一且较克制的桌面工作台比例。
- 数据库弹窗明确展示演示库名称、类型、表数量及未连接真实数据库的状态；图标统一使用固定尺寸的描边 SVG。
- 表单控件统一使用浅透底色、细边框及 6 px 圆角；复选框使用浅透底、4 px 圆角和深绿勾线，保留方形勾选语义，减少动效使用实色滑动开关。输入错误使用暖红提示并关联错误文本，禁用按钮无悬浮位移。
- 背景以低饱和灰白与浅蓝为主，绿意集中在左上；清透外壳和侧栏使用中性透明白，降低底部绿色叠加染色。保留环境色与边缘高光，让玻璃仍有可辨认的层次。
- 右上使用无明确轮廓的渐变光照，移除原先像太阳的圆形装饰，减少对工作区的干扰。
- 字体分为界面与代码标识两组：正文、按钮、预览内容和规则样例使用跨平台系统无衬线字体栈；字段名、类型及预览列标题保留等宽字体并显式提供中文回退。调整常用文字字号与字重，不依赖外部字体下载。实际字形随操作系统已安装字体变化。
- 配置管理使用“文档＋参数”图标；工作台、运行记录及“数据表＋嫩芽”品牌图标保留。下拉浮层使用更浅的中性底色，底部汇总、样例卡片与弹窗表清单通过淡底色、模糊内光和扩散阴影形成自然过渡，避免深色描边与硬高光。
- 确认弹窗中的表名使用与正文一致的 13 px 常规字重无衬线字体，行数使用等宽数字对齐，避免浏览器默认 code 字体造成突兀感。
- 侧栏复选框与整行内容垂直居中。下拉菜单用浅绿色与勾号标记当前选项，鼠标展开显示轻光晕，键盘操作保留明确焦点环。主按钮保留绿色强调，使用轻透着色、柔和内光与扩散阴影；顶部数据表与嫩芽为品牌标识，底部嫩芽仅作辅助装饰。
- 下拉菜单保留原生 select 与键盘操作，支持 `appearance: base-select` 的浏览器使用统一浮层、选中标记及方向箭头；不支持时使用原生选项菜单。日期弹出面板也保留浏览器原生行为，不能宣称所有浏览器弹层外观完全一致。
- 所有模糊只处理网页内部图层，不调用操作系统原生材质。
- 小窗口重排侧栏，数据表在自身容器内横向滚动。
- 支持系统减少动效偏好、减少透明度偏好及无 backdrop-filter 的实色回退。
- 原型中的规则参数仅用于体验，不是 Core 配置格式或完整生成能力契约。
- 此目录由既有 MkDocs `exclude_docs` 排除，不属于正式用户文档或 Web 发行包。

跨平台视觉效果需要在 Windows、macOS、Linux 的实际浏览器环境分别验收，当前本机预览不能代表三端均已验证。
