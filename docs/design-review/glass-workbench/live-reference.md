# 可运行组件交互样板

入口：启动正式 `sqlseed-web` 后访问 <http://127.0.0.1:8630/static/design-system.html>。

这是代码与设计共同维护的参考页面。它直接复用正式 `style.css`、`theme.js`、`theme-control.js`、`ui.js`、`dropdown.js`、`date-picker.js` 和 `graph.js`，不调用业务 API、不连接数据库、不保存工作台草稿。固定业务样例在刷新后恢复初始状态，外观偏好仍在浏览器保留。页面自己的 CSS 仅负责 `.ds-*` 排版，不定义另一套主题、材质或控件。

## 覆盖范围

| 区域 | 可以操作的内容 | 需要观察的结果 |
| --- | --- | --- |
| 外观 | 页头浅色、深色、跟随系统 | 默认浅色；与正式“设置 → 外观”同步浏览器本地偏好，系统跟随自动更新，不请求 AI 或业务 API |
| 材质与文字 | 控制层、阅读层、内嵌说明和混排样例 | 中英文 UI 使用圆角字形，代码保留等宽；明暗模式保持同一材质层级、清晰文字与状态色 |
| 基础控件 | 主次按钮、按下状态、演示加载、复选/单选、表单分组、无效输入 | 悬停柔阴影、不移动；选择控件柔边、分组浅边；禁用输入无凸起；已选与焦点独立保留，修复后错误消失 |
| 下拉与日期 | 正式 dropdown、12 项语言与地区长列表、日期文本与日历 | 活动浅灰、已选浅绿与勾号；浏览不提前提交；长菜单有上下滚动按钮，短菜单无按钮；无效日期保留并提示 |
| 弹窗与抽屉 | 确认样例、YAML 文本、带下拉和日期的规则抽屉 | 背景不跳动；嵌套浮层逐层关闭；取消与应用分离；焦点恢复 |
| 关系图 | 固定结构上的范围切换、搜索、路径、缩放、节点和连线 | 范围底板短滑动，不延迟切换、不移动文字；查看节点不修改固定生成范围；列映射正确，分数像素下无循环跳动 |

模拟加载的 900 毫秒只用于展示禁用和恢复，不能代表正式操作性能。关系图的空“待处理”没有执行依赖校验，不能当成业务检查通过。除浏览器外观偏好外，组件样板的交互结果仅保留在当前页面；正式工作台的模型、连接及执行流程不受影响。

静态检查时把鼠标移到空白区域：普通按钮、输入与下拉共用轻高光和短阴影，输入框四边均匀，不再单独加深下沿，复选/单选柔边下的形状与标记可辨，表单分组只使用浅容器边缘。“验收时看什么”整行有常驻浅底及展开提示；Tab 聚焦后用 Space / Enter 开合，观察文字和箭头随状态变化。悬停不加深选择控件边框；键盘焦点、无效输入和禁用仍须各自可辨；禁用输入与文本域没有凸起阴影，悬停也不恢复。

文字检查使用同一缩放比例，对照“用户基础信息”“每一行，都有依据。”与按钮标签的圆角笔端。中英文 UI 均使用随包分发的寒蝉圆黑 400/500，不再用 `unicode-range` 限定 CJK 范围；`Faker`、`Mimesis`、`users`、`orders` 等英文 UI 也使用圆角字形，`user_id INTEGER`、YAML、SQL 与路径等代码仍使用原有等宽字体。检查本地字体加载后文字未裁切、控件未溢出；对实际业务中的缺字与回退另作核验，不能仅凭字体名称或字重推断实际渲染已通过。

关系图的范围选择为浅槽中的凸起当前项；点击只让选中底板滑动 160ms，真实范围与选中语义立即更新，按钮和文字不动。初载及容器尺寸变化直接定位，快速连续切换应从当前位置转向；减少动态效果时不播放过渡，强制颜色模式以系统选中色表达。缩放、适应画布和路径操作与普通按钮共用材质；检查已选状态悬停后仍然保留，禁用按钮无凸起阴影。打开日历检查四个年月导航、跳转和底部操作；翻月/翻年只浏览，选具体日期才提交，取消恢复入口焦点。

外观检查应分别覆盖浅色与深色的按钮、输入、浮层、日历、图例和关系箭头。选择“跟随系统”后改变系统明暗设置，确认自动更新；选择固定模式时不跟随。在同一来源的正式设置与样板标签页间切换，检查偏好同步和刷新保留。外观检查不触发 AI 分析或业务请求，不能代替目标平台的字体与可访问性实测。

固定关系图中 orders → order_items 应直连，products → order_items 应从下方短路径接入，避免跨到 orders 上方再折返。点线段验证列映射，开启字段标签后验证线段和缩放未改变。排线在有限候选内优先减少折点，再比较距离；密集布局保留安全通道，未宣称无交叉或全局最优。

语言与地区为独立的固定列表，不修改生成引擎样例，也不表示已安装引擎支持全部列出的 locale。展开后检查以下动作；已提交值在下方单独显示：

1. 普通模式不显示下拉原生滑块；只有内容溢出时出现上下滚动按钮。点击可用方向浏览后续选项，不改变勾号和已提交值；停留在箭头上不自动滚动。
2. 到达顶部或底部时，相应方向不可用且不显示图标，保留按钮位置以避免列表跳动；短的生成引擎菜单不出现滚动按钮。
3. 用滚轮或触控浏览，再用方向键、Home / End 浏览首尾；分别测试 Enter 提交与 Escape 取消。按钮点击后键盘仍能继续从下拉触发器操作。
4. 高对比度时恢复原生滑块、系统配色和默认宽度，上下滚动按钮隐藏；检查滚动与选中轮廓仍可辨。页面、面板和表格继续保留中性滚动条，不随下拉一并隐藏。

## 维护方式

1. 先在真实业务中修复或完善共享组件，再用本页观察各状态是否一致。不要只给样板补一层美化样式。
2. 新增组件时加入明确、固定的初始值和验收动作；真实表名、长文本、错误与禁用状态应同时出现。
3. 用键盘和鼠标检查；Windows、macOS、Linux 的实际字体、缩放、滚动条，以及浏览器的透明度与动态效果回退分别记录。
4. 截图只能核对当时的视觉状态；下拉提交、弹窗焦点、滚动稳定性和错误恢复还需实际操作。设计稿应对应同一套变量与组件，不维护与正式实现分离的独立皮肤。
5. 同时检查宿主生命周期：下拉或日历打开后禁用入口不能提交；隐藏设置分区后不留下浮层；短窗口中取消日历应回到抽屉入口，页面与抽屉都不回跳。这些边界由共享组件回归与实际浏览器检查共同覆盖。

本页是可运行参考，不预先宣称跨平台或辅助技术验收通过。当前验收证据应写入本次评审记录，不能把历史测试数量自动当成本次结论。

## 设计来源

- [寒蝉圆黑体](https://github.com/Warren2060/ChillRoundGothic)：基于简体思源黑体的圆角字形；本地资源使用 SIL OFL 1.1，中英文 UI 共用圆角字形，代码保留等宽字体。
- [Radix Select](https://www.radix-ui.com/primitives/docs/components/select#with-custom-scrollbar)：参考其隐藏原生滑块、用上下按钮提示长菜单溢出的组织方式；本项目沿用自己的原生 DOM 组件，不引入依赖，采用点击滚动而非悬停定时器。
- [Fluent Elevation](https://fluent2.microsoft.design/elevation)：用一致光源、短阴影和柔阴影表达不同层级，不意味着所有元素都需浮起。
- [W3C 非文本对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)：识别控件和状态所必需的视觉信息保持足够对比；柔阴影不能取代勾号、轮廓及焦点。

- [Apple HIG：Materials](https://developer.apple.com/design/human-interface-guidelines/materials)：区分控制层与内容层，节制使用 Liquid Glass。
- [Microsoft：Materials in Windows](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/materials)：Acrylic 与 Mica 的用途和层级。
- [microsoft/WinUI-Gallery](https://github.com/microsoft/WinUI-Gallery)：官方可交互组件、代码与可访问性示例。
- [microsoft/fluentui](https://github.com/microsoft/fluentui)：Web 组件状态和设计变量的组织参考。
- [rdev/liquid-glass-react](https://github.com/rdev/liquid-glass-react)：社区折射效果参考，作者明确部分浏览器限制；未作为本项目依赖。

原生系统材质与网页内的 CSS 玻璃效果不同。这里借鉴设计原则，核心功能不依赖原生操作系统特效，也不以持续折射动画作为信息传达方式。
